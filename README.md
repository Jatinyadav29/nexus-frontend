# 🚀 Nexus 2.0 (Frontend)
![Nexus Banner](https://res.cloudinary.com/dxsoxrsdf/image/upload/v1777309349/Screenshot_2026-04-27_at_10.32.23_PM_goiynu.png)

**Nexus 2.0** is a centralized productivity and gaming management hub built with a fully custom React architecture. This repository contains the client-side code, featuring dynamic state management, smooth UI animations, and secure routing.

🌐 **Live Demo:** [nexus-frontend-lyart.vercel.app](https://nexus-frontend-lyart.vercel.app/)

## ✨ Key Features
* **Component-Driven UI:** Built with React and styled for a premium, zero-latency aesthetic.
* **Dynamic Booking Engine:** Real-time visual station selection with live hardware specs.
* **Pro-Circuit Portal:** Complex form handling for multi-player tournament registrations.
* **Comms Relay:** Fully integrated, state-managed messaging portal for user-to-admin transmissions.

## 🛠️ Tech Stack
* **Framework:** React.js
* **Styling:** Tailwind CSS / Bootstrap 5 (adjust based on what you actually used)
* **Animations:** GSAP / Lenis (if applicable)
* **Deployment:** Vercel

## 🚀 Run it Locally
1. Clone the repo: `git clone https://github.com/yourusername/nexus-frontend.git`
2. Install dependencies: `npm install`
3. Create a `.env` file and add your backend API URL: `REACT_APP_API_URL=http://localhost:5000`
4. Start the server: `npm start`
