## ✨ Core Features
* **Component-Driven UI:** Built with a fully custom React architecture for a premium, seamless aesthetic.
* **Dynamic Booking Engine:** Real-time visual station selection with live hardware specs and database locking.
* **Pro-Circuit Portal:** Complex form handling for multi-player tournament registrations with relational data mapping.
* **Comms Relay:** Fully integrated, state-managed messaging portal for user-to-admin transmissions.

## 🚀 Run it Locally

**1. Clone the repository:**
```bash
git clone https://github.com/Jatinyadav29/nexus-frontend.git
cd nexus-frontend
```

**2. Install dependencies:**
```bash
npm install
```

**3. Configure Environment Variables:**
Create a `.env` file in the root directory and connect it to your local or live backend:
```env
REACT_APP_API_URL=http://localhost:5000
```

**4. Initiate Deployment:**
```bash
npm start
```
