# Contributing to Nexus 2.0

First off, thank you for considering contributing to Nexus! This project was built as a learning experience, and contributions of any size — whether it's fixing a typo, squashing a bug, or proposing a new feature — are highly appreciated. 🙌

## How to Contribute

Follow these steps to get your code merged smoothly:

### 1. Fork and Clone

Fork the repository to your own GitHub account, then clone it locally:

```bash
git clone https://github.com/your-username/nexus.git
cd nexus
```

### 2. Create a Branch

Create a new branch for your feature or bug fix. Use a clear, descriptive branch name:

```bash
git checkout -b feature/dark-mode
# or
git checkout -b bugfix/login-crash
```

### 3. Make Your Changes

- Write your code and keep your commits clear and descriptive.
- Follow the [Code Guidelines](#code-guidelines) below.

### 4. Push and Open a Pull Request

Push your branch to your forked repository, then open a Pull Request against our `main` branch:

```bash
git push origin your-branch-name
```

> When opening the PR, fill out the provided PR template so we understand what your changes do and why.

---

## Code Guidelines

- This is a **MERN stack** project — please follow standard **JavaScript/React** conventions.
- If you're adding a new feature, **test it locally** before submitting the PR.
- Keep code clean and well-commented, especially in complex areas.
